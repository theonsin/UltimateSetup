# Ultimate Setup

Modern installer for Last Chaos Ultimate.

![Platform](https://img.shields.io/badge/.NET-8.0-blue)
![Windows](https://img.shields.io/badge/Windows-10%2F11-green)
![Status](https://img.shields.io/badge/Status-Beta-orange)

## Features

- Modern custom UI
- Automatic game download
- Archive extraction
- Free disk space validation
- Existing installation detection
- Smooth progress animations
- Automatic launcher start after installation
- Custom borderless design
